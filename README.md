# Cxds Studio GitHub Pages

Google Sites の掲載内容をもとに再構築した静的サイトです。

## アップロード
このフォルダの中身を `cxdsstudio/cxdsstudio.github.io` リポジトリのルートへ配置してください。

## 重要: app-ads.txt
このZIPには `app-ads.txt` を含めていません。
現在GitHubリポジトリに置いてある、AdMobで使用中の `app-ads.txt` は削除・上書きしないでください。

## 主なURL
- `/` ホーム
- `/apps/` アプリ
- `/games/` ゲーム
- `/privacy-policy/` プライバシーポリシー
- `/updates/.../` 各製品の最新情報

`CNAME` は `cxdsstudio.com` を保持するため同梱しています。
